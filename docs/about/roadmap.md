# Roadmap

The public roadmap lives in [`ROADMAP.md`](https://github.com/genspark-ai/genoffice/blob/main/ROADMAP.md).
This page is a snapshot for documentation readers.

## M0 — Day 14 — public repo skeleton

- [x] Apache-2.0 monorepo on GitHub.
- [x] README + CONTRIBUTING + CODE_OF_CONDUCT + SECURITY.
- [x] CI: typecheck + test + lint.
- [x] Release workflow: npm + Docker image + Pages.
- [x] VitePress docs skeleton.

## M1 — Web SDK + REST API + iframe Embed (Week 4)

- [x] `@genoffice/web-sdk` with ESM / CJS / UMD.
- [x] REST API v1 (health, auth, files, AI, KB, webhooks).
- [x] iframe Embed endpoint at `/embed/:docId`.
- [x] Webhook firing on every save.
- [x] Three example projects (basic, react, vue).
- [ ] IPC reference regenerated by `tools/gen-ipc-docs.mjs`.

## M2 — Open AI ecosystem (Week 8)

- [x] Provider plugin interface (`packages/ai-provider/src/provider-plugin.ts`).

- [ ] 10 official Skills published.
