### `docs:respell-kick`

The desktop main process types one trusted space and the renderer scrubs it back out (see `apps/docs/src/main/docs-main.ts` docs:respell-kick). The web renderer cannot deliver a trusted keystroke; a browser-driven input event is *untrusted* and does not respell Blink anyway. Answering the channel here turns the caller's swallowed 404 (`IPC_NO_HANDLER`) into an explicit success so the renderer's idempotent kick just no-ops without logging an error. Spellcheck will respell as soon as the user types — same final state as the desktop path, just without the synthetic keystroke.

- `apps/web-server/src/docs/index.ts:122`
